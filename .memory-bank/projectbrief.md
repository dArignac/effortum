# Project Brief

## Mission
Effortum is a time tracking application that stores all data locally in the browser's Local Storage. It allows users to track their work time, create projects, and view detailed reports.

## Primary users
End users who need to track their work time and productivity.

## Success criteria
- Users can easily track their time spent on different tasks
- Data is persisted locally in the browser
- Reports and analytics are available for productivity insights
- The application works reliably across different browsers
